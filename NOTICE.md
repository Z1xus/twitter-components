Twitter Components is an independent implementation. The layout and action icons follow the X web interface captured on 13 September 2026. X and Twitter names and marks belong to their respective owners. This project is not affiliated with X.  

The package does not include captured posts, avatars, private archive records, or Chirp font files. Applications supply their own content and fonts.

The API design references vercel/react-tweet, which uses the MIT license. This package contains no code from that project.
